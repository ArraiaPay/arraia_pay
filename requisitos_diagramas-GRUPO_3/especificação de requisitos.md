# Especificação de Requisitos

| ID | Como fazer | Tipo | Descrição | O que precisa fazer | Como realiza o requisito |
|---|---|---|---|---|---|
| RF01 | Criar cadastro de produtos | Funcional | O sistema deve permitir cadastrar produtos com informações como ID, nome, preço e quantidade em estoque. | Cadastrar e armazenar os dados de cada produto. | Por meio de um formulário de cadastro de produtos. |
| RF02 | Criar identificação das barracas | Funcional | O sistema deve permitir cadastrar e identificar cada barraca por meio de um ID único. | Identificar cada barraca de forma única. | Por meio de um cadastro que atribua um ID exclusivo para cada barraca. |
| RF03 | Criar cadastro de preços | Funcional | O sistema deve permitir informar e atualizar o preço de cada produto vendido nas barracas. | Cadastrar e atualizar o preço dos produtos. | Por meio de um campo de preço no cadastro ou edição do produto. |
| RF04 | Criar registro do comprador | Funcional | O sistema deve permitir registrar ou identificar o comprador no momento da realização da venda. | Registrar os dados ou identificação do comprador. | Por meio de um campo de identificação do comprador no registro da venda. |
| RF05 | Criar controle de estoque | Funcional | O sistema deve permitir consultar e controlar a quantidade disponível de cada produto em estoque. | Controlar e consultar a quantidade disponível dos produtos. | Por meio de uma área de controle que mostre a quantidade disponível de cada produto. |
| RF06 | Implementar atualização automática do estoque | Funcional | O sistema deve diminuir automaticamente a quantidade disponível do produto no estoque após a confirmação de cada venda. | Atualizar automaticamente a quantidade disponível após uma venda. | Após a confirmação da venda, o sistema subtrai automaticamente a quantidade vendida do estoque. |
| RF07 | Criar registro de vendas | Funcional | O sistema deve registrar as vendas realizadas, associando os produtos, a barraca, o comprador e o valor da compra. | Registrar todas as informações relacionadas a cada venda. | Por meio do armazenamento dos dados da venda no banco de dados. |
| RF08 | Criar relatório de vendas por barraca | Funcional | O sistema deve gerar relatórios contendo a quantidade de vendas e o faturamento de cada barraca. | Informar a quantidade de vendas e o faturamento de cada barraca. | Por meio da consulta e organização das vendas relacionadas a cada barraca. |
| RF09 | Criar relatório de vendas por produto | Funcional | O sistema deve gerar relatórios mostrando a quantidade vendida e o faturamento de cada produto. | Informar a quantidade vendida e o faturamento de cada produto. | Por meio da consulta e agrupamento das vendas de cada produto. |
| RF10 | Criar consulta de estoque | Funcional | O sistema deve permitir consultar os produtos disponíveis e suas respectivas quantidades em estoque. | Exibir os produtos disponíveis e suas quantidades atuais. | Por meio de uma tela que apresente os produtos e suas quantidades disponíveis. |
| RNF01 | Implementar segurança do sistema | Não funcional | O sistema deve garantir que os dados de compradores, produtos e vendas sejam armazenados de forma segura. | Proteger os dados armazenados no sistema. | Por meio de autenticação, controle de acesso e proteção dos dados armazenados. |
| RNF02 | Otimizar o desempenho do sistema | Não funcional | O sistema deve atualizar as informações de vendas e estoque rapidamente após cada operação. | Garantir respostas rápidas durante as operações do sistema. | Por meio de operações otimizadas para realizar as atualizações rapidamente. |
| RNF03 | Desenvolver interface intuitiva | Não funcional | O sistema deve possuir uma interface simples e intuitiva para facilitar o uso pelos responsáveis pelas barracas. | Facilitar a utilização do sistema pelos responsáveis pelas barracas. | Por meio de uma interface organizada, com menus e campos de fácil compreensão. |
| RNF04 | Implementar validação dos dados | Não funcional | O sistema deve garantir que os registros de estoque e vendas permaneçam consistentes e sem informações duplicadas ou incorretas. | Garantir que os dados cadastrados sejam válidos e consistentes. | Por meio de validações e regras que impeçam o cadastro de informações inválidas ou duplicadas. |
